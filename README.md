# 京东搬运助手 JDMove（Chrome 插件）

采集京东商品详情页（标题、参数、主图、详情图、规格），在你自己的京东 POP 店铺后台（京麦 `wares-jdm.jd.com`）自动选择类目、填写表单、上传图片，然后保存草稿或提交。

## 安装

1. 打开 `chrome://extensions`，右上角开启「开发者模式」。
2. 点「加载已解压的扩展程序」，选择本目录（包含 `manifest.json` 的 `JDMove` 文件夹）。
3. 在插件详情页打开 **「在无痕模式下启用」**（采集需要，见下文）。

## 为什么采集要用无痕窗口

京东不允许**商家账号**查看其他店铺的商品详情，会跳到 `bizsafe-intercept.jd.com`，提示“请使用消费者购物账号”。同一个 Chrome 用户下所有 `*.jd.com` 页面共用一套登录状态，所以：

- **发布**：在普通窗口进行，使用你已登录的商家后台。
- **采集**：插件会打开一个**无痕工作窗口**（Cookie 与普通窗口隔离）。第一次请在这个无痕窗口里登录一个**消费者京东账号**，之后可以连续采集；关闭所有无痕窗口后需要重新登录。

也可以在另一个 Chrome 用户 / 另一台电脑里安装插件采集，然后在任务面板中「导出采集数据」，到商家这边「导入」后再发布。

## 使用流程

1. 点击插件图标 →「打开任务面板」。
2. 「添加链接」：粘贴商品链接或 SKU，一行一个，也可以粘贴整段文本。也可以在商品页右下角点「搬运此商品」，或在店铺/搜索列表页用弹窗里的「提取当前页所有商品链接」。
3. 「采集选中」：在无痕工作窗口中逐条打开并采集，每条之间随机间隔（默认 8～15 秒）。
4. 检查 / 「编辑」：可以修改标题、售价、库存、品牌和属性；也可以搜索并指定店铺类目，勾选“记住”后，同一源类目以后会自动使用这个类目。
5. 「发布选中」：在普通工作窗口里打开发布页，按顺序完成：类目 → 标题 → 品牌 → 属性 → 主图上传 → 销售属性/SKU 价格库存 → SKU 属性 → 详情图转存与写入 → 最后按设置**保存草稿**（默认）或提交。

执行批量任务时请**保持任务面板标签页打开**。工作窗口不要最小化，否则后台页面的下拉框和弹层可能无法正常工作。

## 设置说明

| 项目 | 说明 |
| --- | --- |
| 采集间隔 | 京东对频繁访问有频控。遇到频控/验证页时任务会自动暂停，你手动处理后再点继续 |
| 价格 | 售价 = 源价格 × 倍率 + 加价，取整方式可选（分/角/元/尾数 .9） |
| 标题 | 前缀、后缀、删除词；按京东规则（汉字算 2 个字符）截断到 60 |
| 填写完成后 | 只填写不保存 / 保存草稿 / 提交暂不上架 / 提交并上架 |
| 属性默认值 | 源页面没有对应参数时使用，每行写一条“属性名=值” |
| 类目映射 | 每行写一条：`源类目末级路径 => 目标类目ID路径 \| 名称` |

## 注意事项

- **默认只采集当前链接这一个规格**。京东每个规格都是独立 SKU、价格各不相同，页面上只能拿到当前规格的价格。要一次带上全部规格，可以在设置里勾选“采集全部规格”，然后在发布前逐个核对售价；也可以把每个规格的链接分别添加进来。
- 价格优先取「京东价」；页面上只有补贴价/活动价时，改取原价，避免按临时低价铺货。
- 源页面没有“净含量/规格”参数时，会从规格值或标题中识别“480g / 1.5L”这样的写法来填写。
- **品牌必须是店铺已授权的品牌**，否则该条会标记为「需处理」。
- 部分类目需要先缴纳保证金才能提交，此时只能保存草稿（日志会提示）。
- 自动匹配的必填属性如果没有填上，会在日志中列出来，请在「编辑 → 属性覆盖」中补上。
- 请确认你有权销售所搬运的商品，并遵守京东平台对图片和描述的使用规则。插件不会绕过京东的验证码或频控。

## 开发

```bash
npm test          # 单元测试（node:test，无依赖）
npm run coverage  # 覆盖率
npm run icons     # 重新生成图标
```

目录结构：

- `src/shared/`：纯函数，包括归一化、属性映射、SKU 计划、类目匹配、价格、标题、设置、仓储，有单元测试覆盖
- `src/inject/`：注入页面主世界的脚本（`jd-item-extract.js` 用于商品页，`backend-*.js` 用于商家后台）
- `src/lib/`：扩展侧的流程编排（采集、发布、图片处理、任务队列）
- `src/dashboard/`、`src/popup/`、`src/content/`、`src/background/`：界面和入口
